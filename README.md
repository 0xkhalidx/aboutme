# 🌐 AboutMe - Personal Website

A simple and flexible **personal website** that allows you to showcase your information or project details in a clean way.  
It comes with a **config (cfg)** file so you can easily edit the content without touching the main code.  

---

## ✨ Features
- Clean and minimal design.  
- Easy customization via **cfg** file.  
- Perfect for personal portfolios or project landing pages.  
- **Open Source** – free to use and modify.
